# TypeScript

Verification tags: `[lint]` tsc / ESLint, `[test]` automated test, `[review]` review only.

- TypeScript is pinned to **6.0.x** ([ADR-0001](../../docs/adr/0001-tech-stack.md)); do not upgrade to 7 until typescript-eslint and @astrojs/check support it. `[review]`
- `tsconfig`:
  - `strict: true`;
  - `noUncheckedIndexedAccess: true`;
  - `exactOptionalPropertyTypes: true`;
  - `noImplicitOverride: true`;
  - `verbatimModuleSyntax: true`.

  The typecheck (`astro check` + `tsc --noEmit`) must pass. `[lint]`
- `any` is forbidden, explicit or implicit. Use `unknown` and narrow with type guards. `[lint]` (`@typescript-eslint/no-explicit-any`, `no-unsafe-*`)
- Non-null assertion `!` only with a same-line comment explaining why it is safe. `[lint]` (`@typescript-eslint/no-non-null-assertion` as error; disable comments require a description: `eslint-comments/require-description`)
- `@ts-ignore` is forbidden. `@ts-expect-error` needs a description. `[lint]` (`@typescript-eslint/ban-ts-comment`)
- Type-only imports use `import type`. `[lint]` (`@typescript-eslint/consistent-type-imports`)
- **Named exports only.** Default exports are allowed only where a framework requires them (`astro.config.*`, Astro / Vitest / Playwright config files). `[lint]` (`no-restricted-syntax` on default exports, off for `*.config.*`)
- **API contract types** come from one source: `src/lib/api/schema.d.ts`, generated by `openapi-typescript` from FastAPI's OpenAPI. It is never edited by hand, and hand-written duplicates of API types are forbidden. A CI check fails if the file is stale. `[test]`
- **SSE events** are parsed into the generated `ChatEvent` discriminated union, and an exhaustive `switch` on `type` uses `never` in the default branch. `[lint]` (`@typescript-eslint/switch-exhaustiveness-check`) `[test]`
- **Untrusted data** (network, `localStorage`, URL params) is validated at the boundary (Zod or hand-written guards) before use. `[review]` `[test]`
- No floating promises. Async errors are handled. `[lint]` (`@typescript-eslint/no-floating-promises`, `no-misused-promises`)
- Prefer `readonly` arrays and properties for props and config objects. `[review]`
