**Role**

- Developed JavaScript scripts that automated technical support work.
- Built and maintained one-page websites (landing pages).
- Handled customer inquiries, set up call routing, installed and configured software, and set up auto-dialer servers.
- Controlled financial transactions and maintained reporting documentation.

**Highlight: NumbersValidator**

I noticed that clients' phone-number databases were often in the wrong format and that clients could not easily check whether a number was valid or which country it belonged to. I came up with a tool to solve this and built it end to end in vanilla JavaScript: a web service for validating, cleaning, correcting and converting phone numbers. Clients used it for about six months; company revenue grew by 5% during that period.
