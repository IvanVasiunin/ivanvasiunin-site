iGaming platforms: large-scale consumer web products for international markets, across several projects and brands. Team of about 10: developers, QA engineers, a product owner and a team lead.

**Role**

- Implemented interfaces from designs: semantic HTML, complex SCSS, responsive layouts.
- Built reusable components and adapted existing ones to new requirements without duplication, keeping in mind how a change affects the rest of the shared system.
- Reviewed code for quality, maintainability, readability, reusability, HTML structure, SCSS, performance and alignment with the architecture.
- Investigated complex UI issues down to the root cause and proposed proper fixes instead of workarounds.
- Took part in the full delivery cycle — design, implementation, QA, fixes, release.

**Highlights**

- **Homepage performance.** Traced a poor Lighthouse result to CSS `mask` in buttons repeated across the page, rewrote the components without masks and optimized other heavy gradient components. The team gained a reusable approach to gradient UI that does not hurt rendering.
- **Performance reviews.** Removed unused code, introduced SCSS mixins for reusable styles, optimized images, minimized masks and filters, and fixed layout shift (CLS) during page load.
- **Mentoring.** Mentored a trainee to Junior level.
- **Promotion.** Joined as a strong Middle and was promoted to Senior through an internal grade review: practical tasks and technical questions from two more experienced colleagues.
